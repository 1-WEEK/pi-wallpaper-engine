# Triage Labels

Skills' canonical triage roles use the same names in this repository. Record the
role as `Status:` in the [local issue](issue-tracker.md).

| Label | Meaning |
| --- | --- |
| `needs-triage` | Maintainer needs to evaluate the issue |
| `needs-info` | More information is needed before the work is specified |
| `ready-for-agent` | Fully specified and ready for an agent to implement |
| `ready-for-human` | Requires human implementation |
| `wontfix` | Will not be implemented |

These describe triage readiness or disposition. Completion states and exploration
map execution states follow the effort's conventions in [Issue Tracker](issue-tracker.md).
